# Kapi 0.8.10 / 卡皮 v11 · 小耳机 v3：复盘修复（气泡不压花、花瓣叠加、目光过渡、引导、去掉聊天）

本轮只改运行器源码；宠物素材不变。Windows / Mac 都需要重新编译（推到 GitHub 跑 Actions：`Kapi-win.zip` + `Kapi-mac.zip`）。

## 改了什么（见 README「v0.8.10 修复」）

1. 气泡叠在"画面最高点"之上，不压花，不压人物；不够高就扩窗，脚底不动。
2. 特效 `queue-one`：画布上永远只有一组花瓣 / 爱心 / 奶茶；播放中的再次触发最多排一个。
3. 目光跟随沿相邻方向走，`holdMs` 150 / `crossfadeMs` 260 默认。
4. 引导：首次提示、右键菜单文案、空动作菜单、更新后台词、低频提示台词。
5. `bundle.json` 一次性激活交付包里的宠物；多窗口穿透自愈 + 托盘「恢复交互」「收回其他宠物」。
6. **聊天功能移除**：没有聊天框、没有连接设置、Rust 不再带网络和钥匙串依赖；双击 = 照顾面板。

## 0.8.10 补充验收（头跟随不再跳图）

1. 装任意一只带 8 朝向 / 48 帧环的宠物，鼠标绕着它转 30 秒：期间**不应**看到任何一次闭眼或表情闪过（朝向帧一直在屏幕上）。
2. 鼠标停到它身上（死区）：几秒内会眨眼；摸它 / 点它的表情照常立刻出现。
3. 鼠标回到外圈：又是纯朝向帧。
4. 若宠物包是新 skill 做的（`look/family-check.json` 存在且 ok），死区进出时也不应有光线 / 大小的跳变；旧包（如小耳机 v1）死区进出仍会看出两张图不同——那是素材问题，换运行器只消掉眨眼 / 表情那部分。
